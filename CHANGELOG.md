# Changelog

All notable changes to `omarchy-aesthetic-themes` will be documented in this file.

## [1.0.0] - 2026-09-08

### Added
- Standalone all-in-one suite combining 15 aesthetic themes, static wallpapers, and 15 live MP4 video wallpapers.
- Dedicated `omarchy-live-wallpaper` daemon with 0ms socket hot-swapping and auto-pause.
- Interactive floating HUD selector `omarchy-menu-live-wallpapers`.
- Systemd user service `omarchy-live-wallpaper.service`.
- Comprehensive installation script `install.sh` supporting dry-runs and rollback backups.
- Step-by-step Placement Guide and Live Running Guide.
